Terms used across DemoMart's product and engineering documents. DemoCompany and DemoMart are made up.

| Term | Meaning |
| -- | -- |
| Buyer | Someone who orders on DemoMart, signed in or as a guest |
| Seller | A business that lists products on DemoMart and ships them |
| Listing | A product a seller offers, with one or more variants |
| Variant | One buyable version of a listing, such as a size and colour |
| Cart | Lines a buyer intends to order ([SPEC-046](@SPEC-046)) |
| Checkout | The page where the buyer gives address, shipping and payment ([SPEC-045](@SPEC-045)) |
| Order | What a buyer paid for in one checkout |
| Shipment group | The part of an order one seller ships ([RFC-046](@RFC-046)) |
| Payment intent | The amount to collect for an order and its attempts ([SPEC-048](@SPEC-048)) |
| Soft decline | A card decline the network allows to retry ([RFC-050](@RFC-050)) |
| 3-D Secure | The card network's way for the issuer to confirm the buyer ([RFC-049](@RFC-049)) |
| Capture | Collecting authorised money, per shipment group when it ships |
| Payout | Money DemoMart sends a seller from their balance ([SPEC-057](@SPEC-057)) |
| Commission | DemoMart's share of a sale, by category |
| Minor units | Money as an integer of the smallest unit, such as cents ([ADR-020](@ADR-020)) |
| Hold | Stock reserved for a checkout for 15 minutes ([SPEC-054](@SPEC-054)) |
| Seller Hub | The sellers' web console |
| Market | A delivery country with its currency and payment methods |
| Facet | A filter on search and category pages, such as brand or price |
| Zero-result search | A search that returns nothing |
| Feature flag | A switch that turns a change on for some or all users ([ADR-022](@ADR-022)) |
