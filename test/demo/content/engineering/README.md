DemoCompany's engineering team builds and runs the services behind DemoMart: the web shop, the app's backend, the public API, payments, search and the data platform.

| Project | What it holds |
| -- | -- |
| [Architecture decisions](<decisions/README.md>) | ADR-001 to ADR-050, the decisions that shape every service |
| [Platform](<platform/README.md>) | Kubernetes, delivery, observability and cost |
| [Data and storage](<data/README.md>) | PostgreSQL, Kafka, ClickHouse, events and retention |
| [Public API](<api/README.md>) | The partner API, webhooks and SDKs |

New work starts as an RFC ([RFC process](<RFC process.md>)); a decision that is hard to reverse becomes an ADR ([ADR template](<ADR template.md>)). DemoCompany is a made-up company, and so are all names and numbers here.
